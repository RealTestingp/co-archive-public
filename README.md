# Calgary Opera Archive

A centralized, full-stack microservices web application built for the **Calgary Opera**. This system modernizes over 50 years of physical performance history, into a high-performance relational cloud archive paired with an AI chatbot engine.

## 🛠️ The Tech Stack
* **Frontend:** React, TypeScript, Tailwind CSS
* **Backend Services:** ASP.NET Core (C#)
* **Database Layer:** Azure SQL Database mapped via Entity Framework (EF) Core ORM
* **Media File Pipeline:** Azure Blob Storage (stores legacy scanned program PDFs and images)
* **Authentication/RBAC:** Microsoft Entra ID (managing Admin vs. Standard Staff roles)
* **Reporting Engines:** QuestPDF (PDF compilation) and ClosedXML (.xlsx spreadsheets)
* **AI Orchestration:** Azure OpenAI Service + Azure AI Search.
